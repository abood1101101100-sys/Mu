# 🎵 Telegram Music Bot

A complete Telegram music bot for voice chats using Pyrogram + PyTgCalls.

## ✨ Features
- Play music from YouTube links or search
- Queue system
- Pause/Resume/Skip/Stop controls
- Works in groups and channels
- Replit ready
